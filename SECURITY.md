# Security Policy

CPM22 is a retro-computing emulator and is not designed as a hardened network service.
The console server should normally be bound and exposed only to trusted local systems.

For a security-sensitive report, avoid posting exploit details in a public issue. Use
GitHub private vulnerability reporting if it is enabled for the repository, or contact
the maintainer through the repository owner's GitHub profile.

For ordinary robustness bugs, crashes, malformed input, or local-only failures, use the
bug-report issue template and include a minimal reproducer plus compiler/build details.
